# けん玉練習Webアシストアプリ「けん玉ー１，２，３」 🔴

日本の伝統遊びである「けん玉」ができるようになるWebアシストアプリ「けん玉ー１，２，３」です。  
運動生理学・脳科学・物理学の科学的根拠（『日本の伝統の遊び「けん玉」の熟達ガイド』）に忠実に基づいて設計されており、小学生が自主的・段階的にけん玉を練習し、「ふりけん」や最高峰「世界一周」まで確実にマスターできるよう構成されています。

---

## 🌟 アプリケーションの特長

1. **【全11ステップ完全熟達ロードマップ】**
   - 添付資料に基づき、練習ステップを「持ち方」から最高峰「世界一周」までの全11ステップに詳細分解して網羅。スモールステップで達成感を味わえます。
2. **【精密物理シミュレーター ＆ リアル描写】**
   - 運動方程式（重力 $g = 9.8\text{ m/s}^2$・放物線軌道・振り子運動）および懸垂線（Catenary）糸物理を搭載。
   - 大皿（左90°倒し）・小皿（右90°倒し）・中皿（180°逆さ）への手元回転受け運動、最高点での「空中停止（無重力感 $v=0$）」の1.2秒滞留観察、および「世界一周」での皿から皿への空中放物線ジャンプをリアルタイム描画。
3. **【クリア状況の自動保存（localStorage）＆ 一括リセット機能】**
   - 各ステップの「完了（✔ クリア済！）」記録はブラウザの内部ストレージ（`localStorage`）へ自動保存。次回Webアクセス時も練習の進捗がそのまま復元されます。
   - 「クリア記録リセット」ボタンにより、いつでも練習の進捗を初期化して再挑戦できます。
4. **【タイミング音 ＆ 掛け声音声アシスト】**
   - Web Audio API による木製打撃音「カツン」や衝撃吸収音「スッ...💨」、および Web Speech API による「いち・に・さん」「トントン」「もしもしかめよ」のリアルタイム音声ガイドを搭載。
5. **【小学生に最適化されたデザイン ＆ テラオカ電子ゼミロゴ】**
   - ダークモード（`slate-950`）ベースの上質な UI / UX。
   - ヘッダー右上には指定のプロフィールロゴ（テラオカ電子の自由探究ゼミ）、フッターには指定の著作権表示（`2026 Teraoka-Denshi. All rights reserved.`）を完備。

## 🎯 全11ステップの定義と科学的アプローチ

| ステップ | 技・練習内容 | 科学的原理・アプローチ |
|---|---|---|
| **ステップ 1** | 正しい持ち方（皿グリップ・大皿持ち） | 親指・人差し指で軸を挟み、中指・薬指を皿底へ添えて接触面積増。固有感覚受容体（深部感覚）からの入力情報を向上。 |
| **ステップ 2** | 構えと「いち・に・さん」膝屈伸 | 1:曲げる → 2:伸ばす → 3:かがむ のリズム運動で脳内セロトニン系と小脳の運動記憶を活性化。 |
| **ステップ 3** | 玉の静止 ＆ 垂直引き上げ (10〜20cm) | 玉を完全静止させ、水平初速 $v_x = 0$ で膝の伸びのみで垂直浮上。脳内内部モデルの軌道予測を容易化。 |
| **ステップ 4** | 最高点での「空中停止（無重力感）」捕捉 | 最高点（初速 $v=0$）での1.2秒空中フリーズ・視線オーラ描画により、皿を滑り込ませる位相タイミングを観察学習。 |
| **ステップ 5** | 「大皿」乗せ（左90°倒し） | 大皿口を真上に向け、触れた瞬間に膝を曲げて相対速度を最小化（衝撃力 $F$ を劇的に減衰）。無音着地を目指す。 |
| **ステップ 6** | 小皿（右90°）・中皿（180°）・ろうそく | 手元の回転角度変換（小皿:右90°/中皿:180°）と目標サイズ調整による微小運動制御（モータースキル）の強化。 |
| **ステップ 7** | けん先「とめけん」（垂直挿入） | 穴の位置を注視。「刺すのではなく、穴の下にけん先をそっと添えて落ちてくる穴を迎える」直撃コントロール。 |
| **ステップ 8** | 日本一周の基礎（大皿 ⇄ 小皿 移動） | 膝のバウンド（ポン）を利用し、強化学習（試行錯誤）により運動前野の手元回転角度変換を自動化。 |
| **ステップ 9** | リズム連動「もしかめ」 | 「もしもしかめよ」の歌に合わせ、足踏み（膝屈伸）のリズムに手元の往復回転運動を同期（基底核の定着）。 |
| **ステップ 10** | 玉の回転「ふりけん」 | 糸の振り子運動で前振り順回転（$\omega$）を与え、角運動量保存により軸を安定させて穴の視認性を向上。 |
| **ステップ 11** | 最高峰結合「世界一周」 | 「前振り大皿 → 小皿 → 中皿 → けん先」へと玉が空中放物線ジャンプ！各移行時に「膝クッションリセット」を行い慣性を修正。 |

## 💻 動作環境 ＆ 実行方法

### 1. ローカルでの起動
本アプリは純粋な HTML5 / Vanilla JS / CSS3 (Tailwind CSS) で構築されており、特別なビルドプロセスなしで稼働します。

Python の簡易 HTTP サーバーで起動する場合：
```bash
python -m http.server 8000
```
ブラウザで [http://localhost:8000](http://localhost:8000) へアクセスしてください。

### 2. Vercel でのデプロイ
Vercel へのデプロイが前提として設計されており、`vercel.json` が同梱されています。
- Vercel CLI を使う場合：
  ```bash
  npx vercel --prod
  ```
- GitHub 連携を使う場合：本リポジトリを接続するだけで自動的に静的サイトとしてビルド・デプロイされます。
